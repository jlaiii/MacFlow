MacFlow

Record mouse & keyboard actions like a tape recorder. Replay them infinitely with glass-smooth 150 fps cursor motion.

View on GitHub Get Started

✦ Features

⏺

Record Everything

Mouse clicks, cursor movement, scroll wheel, and all keystrokes — captured with microsecond-precision timing.

▶

Buttery Playback

Custom 150 fps path interpolation via direct OS cursor calls. No teleporting, no stutter — the cursor glides.

✎

Built-in Editor

Double-click any action to tweak its delay. Delete unwanted steps. Insert manual pauses. Full control.

∞

Loop Forever

Repeat macros N times or near-infinitely. Adjust speed from 0.25× to 10×. Automate any repetitive task.

⌨

Global Hotkeys

F8 to record, F9 to stop, F10 to play, F11 to stop playback. All rebindable from the GUI.

🛡

Auto-Stop Safety

Move the mouse or press any key during playback and MacFlow halts instantly. You're always in control.

⏱

Record Delay

Optional countdown before recording starts — switch to your target window, then the capture begins.

💾

Save & Share

Macros are plain JSON. Version-control them, share with teammates, or build a personal library.

⌨ Default Hotkeys

F8Start recording
F9 / EscStop recording
F10Play macro
F11Stop playback

All bindings can be changed from the dropdowns in the bottom bar.

↓ Install

$ git clone https://github.com/jlaiii/MacFlow.git
$ cd MacFlow
$ python macro_recorder.py
# That's it — dependencies auto-install on first run

Requires Python 3.10+. Windows recommended. Auto-installs pynput, pyautogui, and customtkinter.
